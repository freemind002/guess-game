# 🎯 Rust Guessing Game (互動式猜數字遊戲)

一個使用 **Rust** 實作的經典命令列（CLI）猜數字遊戲。本專案不僅涵蓋了 Rust 官方教學的核心範例，更加入了**動態範圍設定**與**完善的輸入防呆驗證機制**，確保使用者在遊玩時不會因輸入無效字元而導致程式崩潰。

---

## ✨ 主要功能特色

* **動態範圍設定**：遊戲開始時，玩家可以自行決定要挑戰的數字範圍（最小值與最大值），系統會自動驗證區間的合理性（`min < max`）。
* **強健的防呆驗證**：
  * **數字解析**：使用 `parse::<i32>()` 安全轉換輸入，若輸入英文或特殊符號會即時提示並要求重新輸入。
  * **範圍邊界檢查**：若玩家輸入超出指定範圍的數字，系統會給予警告並重新提示輸入。
* **智慧比對機制**：利用 `std::cmp::Ordering` 進行大小比較，給予「太大了」、「太小了」或「獲勝！」的即時回饋。
